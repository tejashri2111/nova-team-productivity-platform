# NOVA – Team Productivity Platform

NOVA is a full-stack team productivity and project management platform that helps teams create projects, manage tasks, collaborate with members, and track project progress.

## 🚀 Live Demo

Frontend:
https://nova-frontend-vgmf.onrender.com

Backend:
https://nova-team-productivity-platform-ffq2.onrender.com

## ✨ Features

- User Registration and Login
- JWT Authentication
- Secure Password Hashing
- Create and Manage Projects
- Create and Manage Tasks
- Task Priority Management
- Task Status Tracking
- Project Progress Tracking
- Team Member Management
- Responsive Design
- RESTful APIs
- MongoDB Database
- Deployed on Render
